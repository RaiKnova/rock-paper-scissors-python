# 🪨 Pedra, Papel e Tesoura

Um projeto simples desenvolvido em **Python** que recria o clássico jogo **Pedra, Papel e Tesoura** no terminal.

O jogador escolhe uma opção, o computador faz uma jogada aleatória e o programa determina automaticamente o vencedor de acordo com as regras do jogo.

## 📋 Funcionalidades

- Jogador contra o computador
- Escolha entre Pedra, Papel e Tesoura
- Jogadas do computador geradas aleatoriamente
- Validação de entrada do usuário
- Exibição do resultado da partida

## 💻 Tecnologias utilizadas

- Python 3
- Biblioteca padrão `random`

## ▶️ Como executar

### Pré-requisitos

- Python 3 instalado na máquina

### Passos

1. Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/pedra-papel-tesoura.git
```

2. Acesse a pasta do projeto:

```bash
cd pedra-papel-tesoura
```

3. Execute o programa:

```bash
python main.py
```

## 🎮 Exemplo de uso

```text
Escolha:

3) Tesoura

2
```
